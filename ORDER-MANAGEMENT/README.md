# ORDER-MANAGEMENT
Microservices system for order and inventory management with an API Gateway, User, Order, and Inventory services. Built on Java 25, Spring Boot 3.4.10, Spring Cloud 2024.0.2, Spring Security + JWT, JPA with SQLite, WebFlux, OpenAPI, Docker, and full observability via Micrometer, Zipkin, Prometheus, Grafana, and OpenSearch.
